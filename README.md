# Andever: a self-improving longevity loop

Live at **https://andever.onrender.com** · MCP endpoint at `/mcp`

An agentic loop that proposes longevity interventions and grades them against a
twelve-model panel of epigenetic clocks, then feeds the scores back in to
propose better ones.

```
subject profile
     -> agent proposes an intervention hypothesis
     -> the hypothesis is applied to the subject's methylome
     -> a 12-model bio-eval panel scores the result
     -> hypothesis + score are stored
     -> the agent reads the high scorers and the credit they earned
     -> next hypothesis
```

The report opens with two numbers:

1. **When, on the current trajectory** — median age at death for a cohort with
   this biomarker profile.
2. **When, if you act on aging** — the same figure if the loop's best-scoring
   protocol is followed and held.

## Connect an agent

No key, no account:

```bash
claude mcp add --transport http longevity https://andever.onrender.com/mcp
```

For Codex, in `~/.codex/config.toml`:

```toml
[mcp_servers.longevity]
url = "https://andever.onrender.com/mcp"
```

Then ask it something like *read my health data and tell me what it says about
my longevity*. Tools: `describe_inputs`, `run_longevity_loop`,
`describe_harness`. Only age and sex are required.

**This instance stores nothing.** Profiles exist for the duration of a request.
It also sleeps after 15 minutes idle, so the first request after a quiet spell
waits about 50 seconds while the container wakes.

## What is real and what is modelled

| Piece | Source |
|---|---|
| 12-model eval panel | Horvath, Hannum, PhenoAge, GrimAge V2, DunedinPACE, StocP, StocZ, YingDamAge, YingAdaptAge, DNAmTL, EpiTOC2, Zhang-10, all from biolearn's published coefficients |
| CpG sets behind every mechanism axis | biolearn coefficient tables (EpiTOC, Reinius deconvolution reference, McCartney smoking / BMI / lipid signatures, DNAmTL, Westerman CVD, the GrimAge sub-models) |
| Reference epigenome | Per-CpG regression on GEO series **GSE41169**, 95 whole-blood 450k samples aged 18-65 |
| Panel calibration | Each model's drift per year of age, regressed across real cohort samples |
| Clinical PhenoAge | Levine 2018, from the submitted blood panel |
| Mortality hazard ratios | Published all-cause HRs for GrimAge acceleration (~1.09/yr), DunedinPACE (~1.26/SD) and PhenoAge acceleration (~1.045/yr), applied below their point estimates because the three are correlated |

**Modelled, not measured:** how an intervention moves methylation. No public
dataset maps arbitrary longevity protocols onto per-CpG deltas, so
`intervention.py` simulates it. Scores rank hypotheses. They are not predicted
clinical effects.

## Why the harness is hard to game

An eval an agent can max out teaches it nothing.

1. **Headroom.** Every CpG has a young-adult target from the cohort regression.
   An intervention closes part of the distance and can never overshoot.
2. **User-specific headroom.** Lifestyle burden is written into the baseline
   methylome along real trait-signature directions. A never-smoker has no
   headroom on the smoking axis, so proposing cessation earns nothing.
3. **Five clock families.** Improvements convert to a common unit, years of
   biological aging undone, by dividing each model's change by its own measured
   drift per year. Pushing one clock alone scores badly.
4. **Held-out clocks.** GrimAge V2, DunedinPACE and StocZ drop out of the reward
   on alternating iterations. The difference is reported as a generalisation gap.
5. **Costs.** Off-target methylation change, protocol burden, more than four
   axes, and total change beyond a plausible one-year budget are all charged
   against the benefit.

## How it fits a free instance

biolearn, torch, scipy, scikit-learn and cvxpy are **build-time only**. The
panel is distilled into `loopcore/precomputed/fastpanel.npz` and the mechanism
axes into `axes.npz`, both generated by `tools/` against biolearn. All twelve
clocks match biolearn to float64 rounding, and the axis vectors are bit
identical.

| | with biolearn | distilled |
|---|---|---|
| RSS | 803 MB | **88 MB** |
| 8 iterations | 9.5 s | **0.08 s** |
| boot | 10 s | **0.66 s** |

That is the difference between fitting a free 512 MB instance and not.

Rebuild the artefacts when biolearn changes:

```bash
pip install -r requirements-local.txt
python -m tools.build_fastpanel
python -m tools.build_axes
python -m tools.check_phenoage
```

## Run it locally

```bash
pip install -r requirements.txt
python serve_single_port.py --port 7860
```

That needs no biolearn. For the full stack, including rebuilding the
precomputed artefacts and the Claude-backed hypothesis agent, use
`requirements-local.txt` and `python run.py`.

## Layout

```
serve_single_port.py   interface and MCP endpoint on one port; what Render runs
run.py                 local entry point, two ports
loopcore/
  panels.py            the eval panel, mechanism axes and CpG universe
  fastpanel.py         the distilled numpy panel
  reference.py         the reference epigenome
  bioevals.py          runs the panel, calibrates it, scores a hypothesis
  intervention.py      the in-silico response model
  evidence.py          intervention catalogue with evidence grades
  agent.py             Claude-backed agent and the built-in optimiser
  looprunner.py        the loop
  mortality.py         Gompertz-Makeham lifespan projection
  report.py            the longevity report
  mcp_app.py           MCP server, stateful locally and single-shot when shared
  store.py / memstore.py   SQLite, or nothing at all
  precomputed/         fitted reference and distilled panel, shipped
tools/                 build and verification scripts
web/                   the interface
```

## The two lifespan numbers

They are cohort projections, not predictions about one person. A
Gompertz-Makeham baseline is calibrated so someone with average biomarkers gets
the median age at death a modern high-income life table gives them, then a
proportional-hazards multiplier is applied from the panel. Epigenetic clocks
are validated for ranking mortality risk across groups; two people with
identical panels routinely die twenty years apart, which is why the report
always prints the interquartile band next to the median.

## This is not medical advice

Nothing here is a diagnosis or a treatment plan. Several catalogue entries are
prescription-only and several are preclinical. The report labels both.
