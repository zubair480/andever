# Runtime dependencies for the Render web service.
#
# biolearn, torch, scipy, scikit-learn and cvxpy are deliberately ABSENT. The
# eval panel is precomputed into loopcore/precomputed/fastpanel.npz and the
# mechanism axes into axes.npz, both built by tools/ against biolearn on a
# development machine. All twelve clocks match biolearn to float64 rounding.
# That is what takes the service from 803 MB and 9.5 s per run down to 88 MB
# and 0.08 s, which is the difference between fitting a free 512 MB instance
# and not.
#
# To rebuild those artefacts you need the full stack: see requirements-local.txt.
#
# UPPER BOUNDS ARE NOT DECORATION. A fresh resolve on Render pulled mcp 2.0.0,
# which moved mcp.server.fastmcp and crashed the service on import. pandas 3 and
# numpy 3 are majors this code has never been run against, so they are capped
# too. Raise a bound only after testing against that major.

numpy>=1.19.0,<3
pandas>=2.1.0,<3

# The MCP server and the ASGI stack that serves it alongside the interface.
# mcp 2.x reorganised the package; FastMCP lives elsewhere there.
mcp>=1.27.0,<2
starlette
uvicorn[standard]
